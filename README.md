
Quizy Pop
About
Quizy Pop is a fun and engaging quiz app built with Kotlin and Jetpack Compose. It offers dynamic quizzes across various topics, providing an interactive learning experience. With a sleek UI and smooth navigation, Quizy Pop makes learning enjoyable.

Features
✔️ Multiple Quiz Categories – Choose from different topics to test your knowledge.
✔️ Score Tracking – Keep track of your progress and improve your scores.
✔️ Intuitive UI – Minimalist design with a seamless user experience.
✔️ Smooth Animations – Built with Jetpack Compose for fluid interactions.
